# @dpskh/ui-a2a

[English](README.md) | 中文

基于插件自有 Connection RPC 通道的浏览器端 A2A 协作控制界面。按会话的目录持有唯一权威快照，其中包含连接身份、实时成员清单与项目；概览页、项目页、输入框徽标与快捷面板共享这份状态。会话级长轮询只报告更新后的 revision，目录再拉取完整快照，而不在浏览器重放 Hub 事件。项目目录变更会让所有会话失效；Connection 重置会为当前会话重建基线。浏览器绝不直接打开 Hub WebSocket。

概览页优先展示连接状态和实时成员清单。拓扑图只是辅助信息：最多六名 peer 使用轨道，更多成员改用不会重叠的网格；窄布局隐藏拓扑，保留成员清单。每个节点都携带快照中的对话活动状态：进行中的对话会在对话双方之间画出发光的连线，两个节点呼吸发光；正在处理收到的对话的节点则切换为旋转圆环。成员行和输入框徽标上的身份圆点使用同一套动画语言，所有动画均遵循 `prefers-reduced-motion`。项目页列出 Hub 项目、创建项目，并连接或断开当前会话。Agent 名遵循 Hub 的 32 字符规则，项目名遵循 64 字符规则。输入框面板会适配锚点上方空间，并可通过 Escape 或点击外部关闭。

`/client` 导出插件本体（`apply`/`inject`）。

## 模型体验

无，因为这些视图只渲染 Hub 状态，不产生模型可见内容。

#### KV Cache 影响

无。

## 已知限制与待办

- **没有历史或消息控制** —— 浏览器界面管理实时 presence 与项目；持久历史和发送仍由模型工具与 `/a2a` 命令负责。
- **Host 中介刷新** —— 浏览器在插件自有长轮询或 Connection 重置后重新拉取；它绝不直接消费 Hub WebSocket 事件。
- **推断式 peer 活动** —— 活动状态不经过 hub 线缆：peer 的 `working` 状态来自本地发送的送达回执，直到对方回复或固定窗口结束，因此对方快速完成但未回复时，旋转动画会持续到窗口到期。
