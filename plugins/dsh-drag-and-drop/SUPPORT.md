# Support

## Start here

- Read the [README](README.md) for installation, configuration, usage, and troubleshooting.
- Search existing [issues](https://github.com/omdsh-dev/dsh-drag-and-drop/issues) and [pull requests](https://github.com/omdsh-dev/dsh-drag-and-drop/pulls) before opening a duplicate.

## Where to ask

- Reproducible defect: open a bug report.
- Installation, configuration, or usage question: open a question.
- Focused product improvement: open a feature request.
- Security concern: follow [SECURITY.md](SECURITY.md) and report it privately.
- Code contribution: read [CONTRIBUTING.md](CONTRIBUTING.md) before opening a pull request.

## Information to include

Provide the DSH snapshot and profile, plugin version, browser and OS versions, the file manager or browser used for the drag, whether the browser exposed the original path, minimal reproduction steps, expected behavior, and sanitized output. Remove API keys, authorization headers, complete prompts or conversations, and unrelated workspace paths.
